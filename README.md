## 🚀 Fitur Utama
* **Face Tracking Real-time:** Menangkap mimik wajah (alis, mulut, mata) menggunakan kamera HP.
* **Live Synchronization:** Transmisi data via Wi-Fi lokal tanpa kabel (low latency).
* **VR Avatar Mapping:** Sinkronisasi blendshapes wajah ke karakter 3D di Unity secara presisi.

## 🛠️ Persyaratan Sistem (Requirements)
1.  **Unity Version:** 2021.3 LTS atau lebih baru.
2.  **Package:** Unity Live Capture (`com.unity.live-capture`).
3.  **Mobile App:** Unity Face Capture (iOS/Android).
4.  **Network:** Koneksi Wi-Fi lokal (PC dan HP harus di jaringan yang sama).

## 📦 Cara Menjalankan Project
1.  Clone repository ini ke komputer Anda.
2.  Buka project menggunakan Unity Hub.
3.  Pastikan firewall/antivirus mengizinkan koneksi Unity.
4.  Buka scene utama di folder `Scenes/MainScene`.
5.  Jalankan aplikasi "Unity Face Capture" di HP dan hubungkan ke IP server PC.
6.  Tekan **Play** di Unity Editor.
